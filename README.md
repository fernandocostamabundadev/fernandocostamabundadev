## 🛠️ Como gosto de desenvolver

- **Começo pelo problema:** identifico o objetivo e quem vai usar a solução.
- **Construo por etapas:** mantenho as mudanças claras e fáceis de acompanhar.
- **Verifico o comportamento:** testo fluxos principais e situações inesperadas.
- **Aprendo com feedback:** documento melhorias e aplico o que aprendi no projeto seguinte.
